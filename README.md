# 📚 Literalura - Catálogo de Livros

Desafio de Java e Spring Boot desenvolvido para o programa Oracle Next Education (ONE). O projeto consome a API Gutendex para buscar dados de livros e autores, persistindo-os em um banco de dados PostgreSQL.

## 🚀 Funcionalidades
- **Busca por título:** Consulta a API e salva o livro no banco.
- **Listagem de Livros:** Exibe todos os livros armazenados.
- **Listagem de Autores:** Exibe os autores salvos.
- **Filtro de Autores Vivos:** Busca autores por um determinado ano.
- **Estatísticas por Idioma:** Conta livros por código de idioma (pt, en, fr, es).

## 🛠️ Tecnologias
- Java 17/21
- Spring Boot 3
- Spring Data JPA
- PostgreSQL
- Jackson (Manipulação de JSON)
